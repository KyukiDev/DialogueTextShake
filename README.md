# Dialogue Text Shake for Obsidian

A convenient plugin to make text shake letter-by-letter like video game dialogue.

## How to Use
- Highlight any text and press `Alt + Shift + S` to apply or remove the shake.
  
- Or right-click highlighted text and select **Shake** from the right-click menu.
  
- Use `+!text!+` manually if you prefer typing the syntax.

- It might be a bit iffy but please don't nitpick :sob:
